# Portfolio Testeur QA

Ce portfolio a été réalisé dans le cadre de ma formation de testeuse logiciel chez OpenClassrooms. Il présente mon parcours, mes compétences et les projets réalisés au cours de ma formation en vue de devenir Testeuse QA.

## Objectifs du projet

Ce projet a pour objectifs de :
- présenter mon profil et mon parcours ;
- mettre en avant mes compétences en test logiciel ;
- présenter mes différents projets et réalisations ;
- proposer une vitrine professionnelle accessible en ligne ;
- mettre en pratique les notions de développement, de responsive design, de débogage et de d'optimisation web.

## Technologies utilisées

- HTML5
- CCS3
- Bootstrap
- JavaScript
- Git / GitHub

## Responsive design

Ce site a été conçu pour être consultable sur desktop, tablette et mobile.
